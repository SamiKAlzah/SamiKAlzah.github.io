Rush/Lab

A VR hematology game about accuracy under pressure.

You are the only human in a lab run by androids. Pass a probation set by your supervisor, A-7, then sort blood samples, prioritize urgent orders, run the analyzers and release results while it watches through the window.

Platform
Meta Quest 3 and 3S, hands first with controller fallback
Built with
Unity 6, URP, OpenXR, Meta XR Interaction SDK
Session
A short probation tutorial, then a six-minute shift
Role
Project creator: game design and Unity development

Read. Scan. Rack. Run. Review.

Every tube goes through the same loop. Speed matters, but a careful shift scores an A and a fast, careless one fails.

  1. Read the label

    Every cap is lavender, so the label is the only tell. A red STAT band means urgent.

  2. Scan and register

    Pass the tube through the scanner beam, set the priority, then tap one test to commit the order.

  3. Fill the rack

    Three tubes to a rack. Dock it on an analyzer and the run starts by itself.

  4. Run the analyzer

    Analyzers read registered STAT tubes first, then the rest in slot order.

  5. Review the result

    One decision per visit: release it to the fridge, or send it back for a rerun.

  6. Call the critical

    A critical value goes to the doctor on the wall phone. Calling a normal result counts as a mistake.

Meet A-7, your supervisor.

A hostile android with a handlebar mustache. It runs your probation, heckles every mistake, and only respects results. Pick a reply.

A-7So they actually sent one. A human.

A-7This lab has run without error for 1,204 nights. Let's see how quickly you end that streak.
